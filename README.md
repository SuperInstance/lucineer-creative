# 🎨 Lucineer Creative Pipeline

MMX-powered creative asset generation for Lucineer's worlds.

## What This Does

When Lucineer builds, she doesn't just place blocks — she generates atmosphere:
- **Concept art** via FLUX-2-max or MMX image generation
- **Ambient music** via MMX music synthesis  
- **Build descriptions** via MMX text generation
- **Build previews** via MMX video generation

## Usage

```bash
python3 creative_pipeline.py "build a spooky forest"
```

Outputs to `assets/` directory with generated media.

Part of the [Lucineer system](https://github.com/SuperInstance/lucineer-system).
